# 집중 잠금 (FocusLock)

정해둔 시각까지, 직접 고른 앱만 빼고 나머지 앱을 전부 막아주는 안드로이드 앱입니다.

## 어떻게 동작하나요

안드로이드에는 "다른 앱을 잠근다"는 공식 API가 없습니다. 그래서 실제 앱들(포레스트, 넷그린 등)이 쓰는 방식과 같은 구조를 사용합니다.

1. **접근성 서비스**가 화면 맨 앞에 뜬 앱의 **패키지 이름만** 감지합니다 (화면 내용은 읽지 않음).
2. 잠금이 켜져 있고 그 앱이 허용 목록에 없으면,
3. **전체 화면 차단 화면**을 그 위에 띄웁니다. 뒤로가기를 눌러도 홈으로만 나갑니다.

## APK 만드는 방법

### 방법 A — 깃허브로 빌드 (컴퓨터에 아무것도 설치 안 함)

1. 깃허브에서 새 저장소를 만듭니다 (Private 가능).
2. 이 `FocusLock` 폴더 **안의 내용물**을 저장소 최상위에 올립니다.
   (저장소 루트에 `settings.gradle.kts` 와 `app/` 폴더가 바로 보여야 합니다.)
3. 업로드하면 `.github/workflows/build.yml` 이 자동으로 실행됩니다.
   저장소 **Actions** 탭 → 최근 실행 클릭 → 아래쪽 **Artifacts** 의 `focuslock-debug-apk` 다운로드.
4. 압축을 풀면 `app-debug.apk` 가 나옵니다. 폰으로 옮겨 설치하세요.
   (설치할 때 `출처를 알 수 없는 앱 설치 허용` 을 켜야 합니다.)

자동으로 안 돌면 Actions 탭에서 **Run workflow** 로 수동 실행할 수 있습니다.

### 방법 B — Android Studio

1. Android Studio (Ladybug 이상 권장)에서 `FocusLock` 폴더를 엽니다.
2. Gradle Sync가 끝나면 (`gradle-wrapper.jar` 는 스튜디오가 자동 생성)
   **Build > Build Bundle(s) / APK(s) > Build APK(s)**
3. 완료 알림의 `locate` 를 누르면 `app/build/outputs/apk/debug/app-debug.apk` 위치가 열립니다.
   기기를 USB로 연결했다면 `Run` 버튼만 눌러도 바로 설치됩니다.

### 방법 C — 명령줄

```bash
cd FocusLock
gradle wrapper          # 최초 1회 (Gradle 8.7 필요)
./gradlew assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

> 위 방법들로 나오는 건 **디버그 APK** 입니다. 디버그 키로 자동 서명되어 본인 기기 설치·테스트에는 문제없지만, 플레이 스토어 배포에는 별도 서명 키(release 빌드)가 필요합니다.

- compileSdk 35 / minSdk 26 (Android 8.0 이상)
- Kotlin 2.0 + Jetpack Compose

## 처음 실행 후 설정

1. 앱을 열고 **접근성 설정 열기** → 설치된 앱 → **집중 잠금 서비스** → 켜기
2. 앱으로 돌아와서 **종료 시각**을 고릅니다 (지금보다 이른 시각이면 내일 그 시각까지)
3. 아래 목록에서 **잠금 중에도 쓸 앱**을 체크합니다
4. **잠금 시작**

## 파일 구조

| 파일 | 역할 |
|---|---|
| `MainActivity.kt` | 시간 설정 · 허용 앱 선택 · 잠금 시작 UI |
| `AppBlockerService.kt` | 앞에 뜬 앱 감지 후 차단 (접근성 서비스) |
| `BlockOverlayActivity.kt` | 남은 시간이 보이는 차단 화면 |
| `LockPrefs.kt` | 잠금 종료 시각 · 허용 앱 목록 저장 |

## 알아둘 점

- **전화 앱, 홈 화면, 시스템 UI는 항상 열립니다.** 급한 연락을 막지 않기 위해서입니다.
- **설정 앱은 기본적으로 열립니다.** 그래야 필요할 때 접근성 서비스를 꺼서 빠져나올 수 있습니다. `설정 앱도 잠그기`를 켜면 이 탈출구가 막히니 주의하세요.
- 화면에 **잠금 해제 버튼**을 넣어뒀습니다. 의지를 더 강하게 시험하고 싶다면 `MainActivity.kt`의 `showCancelDialog` 관련 코드를 지우면 됩니다.
- 제조사 배터리 최적화가 서비스를 종료시킬 수 있습니다. **설정 > 배터리 > 앱 절전 제외**에 이 앱을 넣어주세요 (삼성/샤오미 기기에서 특히 중요).
- 재부팅하면 접근성 서비스가 자동으로 다시 켜지지만, 종료 시각은 저장되어 있어 잠금이 이어집니다.
- 이 방식은 안전 모드 부팅이나 접근성 강제 해제로 우회할 수 있습니다. 타인을 강제로 통제하는 용도가 아니라 **본인의 집중용**으로 만들어진 구조입니다.

## 구글 플레이에 올릴 계획이라면

접근성 서비스를 쓰는 앱은 심사 시 **왜 필요한지 설명하는 정책 선언**을 제출해야 합니다. 디지털 웰빙 목적이면 승인되는 카테고리지만, 사전에 Play Console의 접근성 API 정책을 확인해 두세요.
